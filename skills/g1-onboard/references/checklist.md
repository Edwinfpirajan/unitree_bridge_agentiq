# Lista de aceptación

- Perfil de hardware completo, salvo datos secretos fuera de Git.
- Mando, E-stop, cargador, batería y soporte identificados.
- Variante, DOF, manos y firmware confirmados; SDK compatible fijado.
- Interfaz de red dedicada e IP verificadas sin escribir al robot.
- DDS de simulación separado del hardware.
- `g1ctl doctor`, `g1ctl status` y `unittest` pasan en mock.
- Simulación equivalente ejecutada antes del primer comando físico.
- Operador, observador, área, límites y procedimiento de aborto definidos.
